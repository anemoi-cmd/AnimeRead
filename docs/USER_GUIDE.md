# 使用说明

## 开始阅读

点击右上角 **导入书籍**，或者直接把文件拖进窗口。支持 TXT、EPUB、PDF 小说，以及 CBZ／ZIP 压缩包、单张图片和漫画 EPUB。

书籍文件始终留在你原来存放的位置，阅读器只记住它在哪里。从书架删除一本书不会删除文件；文件挪了位置，再导入一次就能接着上次的进度读。

## 翻页

| 想要 | 怎么做 |
| --- | --- |
| 下一页 | 点击正文右半边，或按 `→` `↓` `空格` `PgDn` |
| 上一页 | 点击正文左半边，或按 `←` `↑` `PgUp` |
| 滚轮翻页 | 鼠标滚轮向下是下一页，向上是上一页；放大后的页面会先滚到边缘再翻页 |
| 用手拖着翻 | 翻页方式选“仿真”，从页边横向拖动；拖过一半就翻过去，不到一半会弹回 |
| 跳到某处 | 拖动底部进度条，或打开左上角目录 |
| 全屏 | 按 `F11` 或点右上角全屏按钮，`Esc` 退出 |
| 导入书籍 | `Ctrl` + `O` |
| 阅读设置 | `Ctrl` + `,` |

在文字上按住拖动可以选择、复制文字，不会误翻页。

## 阅读设置

阅读时点右上角的 **阅读设置**：

- **底色**：浅色、深色、纸张、墨水、木纹。纸张类底色会让漫画的白色部分也带上纸感。
- **文字**：小说可以换字体、字号、行距、页边距，也能加粗或倾斜。
- **漫画显示**：自动裁切扫描留下的白边，让画面更大；单页阅读时还可以把左右相连的跨页大图拆成两页，按阅读方向先后显示（从右往左读时先显示右半）。
- **单页／双页**、**翻页方式**（直接切换、滑动、仿真翻书）和仿真动画的快慢。
- **从上往下读**：漫画和小说都可以像网页一样连续滚动，小说会自动接上下一章。
- **雨景、雨声和翻书声**：想要一点氛围时打开。

## 书签与目录

点击顶部的书签图标，就能记住当前这一页。目录按钮里有章节列表和你的所有书签，点一下就能跳过去。

## 书架与分组

首页会显示你上次读到的书和累计阅读时间，点 **继续阅读** 就能回到上次的位置。

一套漫画或小说有很多卷时，可以放进同一个分组，书架上只显示一张卡片：

- 打开 **管理分组**，“检测到的系列”会列出名字相同的多卷书，点一下就能建好分组。
- 也可以在书上点右键，选 **加入分组**。
- 分组名和书名一致时，以后再导入的同名新卷会自动加进去。
- 在分组里可以调整卷的顺序。删除分组不会删除书。

## 漫画画质增强

打开一本漫画，在阅读设置里开启 **超分画质**，阅读器会用显卡让线条和文字更清晰；低分辨率的图片会放大到适合屏幕的尺寸。处理时可以照常翻页，处理好的页面会自动替换。

- **引擎**：一般选 Anime4K，速度快；Waifu2x 是另一种算法，每页大约需要一秒。
- **滤镜**：A 是放大并锐化，B 让线条柔和，C 去除噪点。可以组合，例如“C+A”先去噪再放大。
- **按需处理**：A 会根据屏幕自动决定放大多少（最多 4 倍）。如果原图本来就比屏幕清晰，就不再放大，顶部会显示“原图已足够清晰”，显卡也不用工作，更安静省电。
- 勾选 **画质对比**，拖动中间的分界线，左边是原图、右边是增强后的效果。

这项功能需要独立显卡或核显；电脑没有可用的显卡时会自动关闭，不影响正常阅读。

## 外观与设置

左下角的 **设置** 里可以：

- 更换主题色，设置首页的欢迎语。
- 用自己喜欢的图片或视频作为背景。
- 调节 **液态玻璃** 的通透程度；配合背景壁纸最好看，调到最左就是不透明的。
- 检查并安装软件更新，更新后书籍、书签和阅读进度都会保留。

## 常见问题

**打不开某本书？** 确认文件没有损坏、没有加密。带密码的 PDF 暂时不支持。

**换了电脑想保留记录？** 便携版的记录都在程序旁边的 data 文件夹里，整个文件夹一起复制即可。

**电脑要求？** Windows 10 或 11（64 位）。安装版会自动准备所需的系统组件，便携版解压后直接运行 AnimeRead.exe。
