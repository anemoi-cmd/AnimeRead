# 使用说明

## 快捷键与鼠标

| 操作 | 方法 |
| --- | --- |
| 下一页 | ↓、→、PgDn、Space、Enter；左键点击正文右半边 |
| 上一页 | ↑、←、PgUp；左键点击正文左半边 |
| 拖动翻页 | 仿真模式横向拖动；拖过半屏完成，未过半屏回弹 |
| 导入书籍 | Ctrl + O，或拖入窗口 |
| 阅读设置 | Ctrl + ,；全屏右上角设置按钮 |
| 全屏 | F11；Esc 退出 |

右键不翻页。直接拖选文字可选择和复制；仿真翻页从页边空白或插画处横向拖动。按钮、滑块、对比线和文字选择不触发点击翻页。

## 常用功能

- 阅读设置：单双页、翻页方式、顺序、底色、缩放。TXT／文字 EPUB 可改系统字体、字号、行距、页边距、粗体和斜体；PDF 保留原排版。
- 漫画左右阅读：每页在固定页面框中等比显示，不拉伸；不同比例会留白。双页的封面和末页可能有一侧空白。
- 漫画从上往下：滚轮或上下拖动；翻页键直接定位完整页起点，不播放卷页动画或翻书声。
- 小说从上往下：滚轮或在空白处上下拖动，可连续跨章节；翻页键对齐下一屏／上一屏，读完章节后进入下一章。
- 书签：点击顶部书签图标添加，在目录的书签列表删除。
- 书架：右键删除书目保留原文件；原文件移动后重新导入可更新位置，保留进度。
- 分组：填写系列名后保存，自动收录同名卷和以后导入的同名卷；可调整卷序、手工添加／移除、关闭自动收录。删除分组保留书目。
- 首页显示上次阅读的书、封面、时间和累计阅读时间。书籍计时在离开阅读或窗口失焦后暂停。
- 外观设置：主题色、欢迎语、背景图片或视频。图片最大 32 MiB；视频最大 200 MiB，支持 H.264 MP4／WebM。视频静音循环，在阅读和窗口失焦时暂停。
- 雨景、雨声和仿真翻书声可在阅读设置分别开关。
- 仿真翻页可调 150–1500 毫秒，数值越小越快；默认 400 毫秒。上下阅读不使用该动画。
- 纸张、墨水、木纹底色会融入漫画白色区域，木纹带有轻微纹理；浅色保留原图颜色。效果只改变显示，可随时切换；彩页的颜色也会受纸张色影响。
- 侧栏“软件更新”检查新版本，下载后自动重启升级，保留阅读记录。0.9.4 及以前首次需手动升级到 0.9.5。

## 画质增强

在漫画画质中开启“超分画质”，选择引擎和滤镜。勾选“画质对比”后拖动分界线：左边原图，右边增强。处理完成前仍可翻页。

Anime4K 使用显卡加速，需较新的驱动和 WebView2。Waifu2x 可使用支持 Vulkan 的 NVIDIA、AMD、Intel 显卡，包括核显；CPU 不支持。检测不到可用显卡时自动关闭超分，相关选项不可选；显卡或驱动不支持某个引擎时该引擎不可选，处理失败仍可读原图。滤镜是处理步骤，按当前引擎从上到下执行，最多四步。

| 滤镜 | 作用 |
| --- | --- |
| A | 超分，宽高各放大两倍 |
| B | 柔和线条，尺寸不变 |
| C | 降噪，尺寸不变 |

C+B+A 先降噪、再柔和、最后两倍超分；A+A 为四倍。只有 A 改变尺寸。可添加、删除和调整步骤顺序；当前不混用两个引擎。叠加越多，耗时越长。

## 运行与数据

支持 Windows 10／11 的 64 位系统，需 Microsoft WebView2 Runtime；不支持 Windows 7／8。电脑缺少 WebView2 时，安装版需联网下载，便携版需先安装。安装版默认仅安装到当前账户，卸载默认保留阅读记录。便携版解压后运行 AnimeRead.exe，记录保存在旁边的 data 文件夹；请放在可写目录。两个发行包均不附带书籍和阅读记录。
