# 0.9.7 小说朗读方案与素材清单

核对日期：2026-10-23。本文件是开发方案；当前仅完成旧接口核查和配置清理，尚未安装语音引擎、接入朗读或发布 0.9.7。根目录程序与在线更新仍是 0.9.6。

## 目标与第一版范围

让中文 TXT／文字 EPUB 使用用户选定的声音连续朗读；声音素材可以是日语，输出仍是中文。第一版提供播放、暂停、继续、停止、语速、上／下一句、句子高亮、跨章续读和断点恢复。手动翻页不重启生成，打开另一本书会结束旧朗读；可选择是否跟随朗读翻页。

先做单声线叙述。多角色自动分配、翻译后用日语读、章节总结、生图、扫描漫画 OCR 和扫描 PDF 不在这一阶段。文字 PDF 的提取顺序需单独验证后再支持，不能把 PDF 复制出来的乱码当成可用朗读。

### 日语声音为什么可以读中文

基础 TTS 模型提供中文发音与语言能力；参考音频／微调数据提供音色和说话风格。日语录音能用于跨语言合成，但“相似的声音”和“准确、自然的中文”需要分别试听。不会因此得到该说话者真实说中文的录音，也不能保证音色、声调、专名和长文都正确。

日语音频必须配对应的日语原文，不可把字幕翻成中文后当作同一条训练数据。只有取得同一说话者的真实中文录音时，才加入其对应中文标注。另一人的中文录音不能挂到同一个说话者名下。

## 引擎选择

**主路线：GPT-SoVITS，先参考音频推理，再根据结果决定是否微调。** 第一轮优先 v2Pro 系列作为 Windows／较小显存的基线；对高质量参考音频额外试听 v5 Turbo。版本选择是本项目的工程判断，最终按本机中文长文试听和资源占用确定。

| 候选 | 在本项目中的用途 | 边界 |
| --- | --- | --- |
| GPT-SoVITS v2Pro 系列 | 先跑通日语声线读中文，需要时做少样本微调 | 固定代码、底模和整合环境的匹配版本 |
| GPT-SoVITS v5 Turbo | 干净参考音频下的零样本对照 | 官方当前未验证 v5 少样本微调，不照搬旧训练教程 |
| Qwen3-TTS 0.6B Base | 同一批素材的备用对照，验证中文发音及音色 | 官方提供单说话人微调；8 GB 显存是否够训练需实测 |

GPT-SoVITS 官方说明支持中日跨语言合成；其版本对照明确区分 v2Pro、v5 Turbo 与尚未验证的 v5 微调。[项目说明](https://github.com/RVC-Boss/GPT-SoVITS)、[版本对照](https://github.com/RVC-Boss/GPT-SoVITS/wiki/GPT%E2%80%90SoVITS%E2%80%90features%28Latest%E2%80%90Including%E2%80%90v5%29)。

Qwen3-TTS Base 支持中日等语言的声音克隆，参考音频与准确字幕可以先直接推理；训练流程见其[官方说明](https://github.com/QwenLM/Qwen3-TTS/blob/main/finetuning/README.md)。RVC 是已有语音的音色转换，不能单独把小说文字变成语音，因此不作为首个后端。

这里只做候选比较，阅读器首版只集成试听胜出的一套自定义声音引擎。窗口中的漫画超分继续使用自己的 Anime4K／Waifu2x 管线；语音不通过 WebGPU 超分管线运行。

## 现在收集什么

以下时长、比例和切片范围是本项目的收集建议，不是模型的硬性最低要求或音质保证。**先准备一个说话者的一种稳定声线，交第一批素材即可。**

| 素材 | 第一批：先验证能否用 | 后续：确需微调时 |
| --- | --- | --- |
| 干净参考音频 | 3 段，每段约 5–8 秒，含完整句子 | 保留最稳定的 1–3 段作为固定参考 |
| 同一声线的语音池 | 总计 2–5 分钟 | 先整理 30–60 分钟有效语音；有明确质量收益再增加 |
| 准确原文 | 每段一一对应；日语音频配日语 | 所有训练切片均经人工校对 |
| 未参与训练的验证材料 | 约 20 条中文句子、一段 3–5 分钟中文长文、少量日语句子 | 约 10% 独立录音留作验证；尽量来自不同录音场次 |
| 来源记录 | 原文件、来源、起止时间、说话者／角色、录音条件 | 能追溯每段切片 |
| 发布用途说明 | 是否只在本机试验，是否准备公开下载 | 公开声音包准备覆盖训练、权重及参考音频分发的授权说明 |

公开分发真人声线时，应先确认配音者和录音素材权利方允许拟发布的用途。软件／基础模型许可不等于声音素材许可。第一轮可用自己的录音或明确授权配音，先确认流程和质量。

### 音频标准

- 优先原始 WAV／FLAC；自己录音可用单声道、44.1 或 48 kHz、16／24 bit PCM。原始文件保留原采样率和完整信息，模型需要的重采样在处理副本上完成。
- 已有高质量 OGG 也可先保留原文件；转 WAV 方便处理，不会恢复压缩丢失的细节。不要把低音质音频简单升采样后当作高音质。
- 一段只有一个人的声音，无背景音乐、音效、另一人插话、明显混响或削波。分离／降噪后的音频必须再听，金属声、气泡声和被削掉的辅音会被模型学进去。
- 语气以适合听书的自然叙述为主。扩充数据时可按约 70% 平稳叙述、20% 自然对话、10% 温和情绪收集；先排除唱歌、尖叫、哭喊和极端气声。
- 同一演员的多个角色音色也可能相差很大；一个训练集只放目标声线。不要把几个角色、访谈本音和舞台夸张表演全部混在一起。
- 后续切片以完整句子为单位，约 3–10 秒起步；头尾不截断发音，去除长静音，保留自然呼吸。最终长度服从固定版本的引擎要求。
- 自动识别只做字幕初稿，逐条校对假名、汉字、人名、数字、漏字与标点。不能听写可靠的片段先剔除。

### 目录和标注

素材、Python 环境与模型全部放在 AnimeRead 工程外。可在 D 盘建立独立工作目录，下面只是建议结构，本次不会创建空目录或下载模型：

~~~text
AnimeRead-VoiceLab/
  voice01/
    originals/        原文件，只读保留
    references/       第一批 3 段参考音频及对应文本
    clips/            后续校对后的训练切片
    metadata.csv      每段音频与文本、来源、用途
    validation/       不参与训练的录音和中文测试文本
    source-notes.txt  来源、角色、录音条件与可用范围
~~~

统一素材表使用 UTF-8 CSV，逗号或换行出现在字段中时须正确加引号：

~~~csv
audio,speaker,language,text,source_id,start_ms,end_ms,style,split
clips/0001.wav,voice01,ja,"今日は、静かな一日でした。",session01,1200,7200,narration,train
~~~

这里保留原始日语，不翻译。source_id 对应来源记录，起止时间相对于原文件。引擎确定后再由同一份素材表导出其专用格式，避免人工维护两套字幕。

GPT-SoVITS 的 .list 格式为“音频路径|说话者|语言|原文”；Qwen3-TTS 的训练 JSONL 使用 audio、text、ref_audio 字段。各版本训练入口、采样率和模型文件匹配官方说明，不把任意第三方教程的参数混在一起。

## 素材到可用声音的流程

1. **先试参考音频，不训练。** 检查录音和字幕；固定底模、参考音频和中文测试文本，分别生成短句、自然对话、长文。同一组素材做候选对照。
2. **记录质量与速度。** 分别看音色、中文声调、漏字／重复、人名、停顿、句间一致性。测冷启动、模型常驻后的首段等待、显存峰值、生成耗时／音频时长之比（RTF）。
3. **判断是否需要微调。** 音色已经可用则优先做阅读器接入；中文读音存在系统性问题时先换底模／参考和文本读音处理，不能假定多训几轮就会解决。
4. **需要时整理 30–60 分钟。** 去重、切片、自动识别后人工校对、按录音场次划分训练与验证；验证文本不混入训练。
5. **生成训练特征并做少样本微调。** 采用候选版本的官方步骤，从小批次开始，保存少量中间检查点。不是从零训练一个多语言大模型，也不预先承诺 LoRA 或显存数字。
6. **回到同一组未见过的句子评估。** 比较底模、参考推理和微调；按听感与漏读情况选择检查点，不只看训练损失。不要用模型自己合成的“目标中文”冒充真实录音来验证其正确性。
7. **导出推理所需文件。** 记录引擎版本、底模版本、声线文件、参考音频及准确原文、语言、哈希和许可。丢弃无用训练缓存，不把整个训练环境发给用户。

中文测试至少覆盖普通叙述、问句、多人引号、长句、姓氏／多音字、年月日、时间、百分数、小数、英文缩写与中日混合专名。人名可先用逐书读音词典校正，不接入通用聊天模型。

### 硬件与安装准备

- 当前开发机实测识别为 RTX 5070 Laptop，约 8 GB 显存，32 GB 内存。它适合作为首轮推理／小批次微调试验机，具体版本能否训练仍取决于显存峰值和配置；不承诺 1.7B 全量训练能在本机完成。
- 50 系显卡需支持 Blackwell 的 PyTorch／CUDA 构建。优先官方适配的 Windows 环境，先验证一条句子；不覆盖系统 Rust、C++ 编译库或阅读器环境。[PyTorch 的 Blackwell 支持说明](https://pytorch.org/blog/pytorch-2-7/)。
- 给独立训练工作区先预留约 30–50 GB 作为工程预算，实际按选定底模、环境、原音频和检查点计算；下载前再确认体积。Python、下载缓存和检查点一起放在选定的数据盘，不重新堆进 C 盘或源码目录。
- 素材阶段无需安装 CUDA Toolkit、训练包或所有候选模型。本次不新增 Python、PyTorch、付费 API 或语音 SDK 依赖。

## 接入阅读器与性能边界

数据流：书籍章节 → 清洗文本和稳定句子锚点 → 有界生成队列 → 独立语音进程 → 音频播放 → 当前句高亮／可选跟随。

- **文本按章节提取一次。** TXT／EPUB 共用句子与锚点结构，跳过脚本、导航、重复注音和无正文插画；无字章节自动推进。字号、单双页、全屏和翻页动画不重建语音任务，不把屏幕快照当朗读文本。
- **先播放当前句，提前生成后面两句。** 开始时模型加载一次、参考特征计算一次；每次一个合成任务，整个队列最多三句。按语义与标点分段，长句再安全拆分，不切断人名和数字。队列和音频缓存设容量上限。
- **Rust 管理独立推理进程。** 优先经标准输入／输出交换有任务编号的消息，由 Rust 校验生成音频并交给播放端；不开放公网端口或任意执行命令。实现阶段再设计实际消息，不先添加空 API。
- **取消与暂停分开。** 暂停保留当前播放位置；停止、换书、跳章或切声线使旧任务失效，迟到结果不播放。超时可回收独立进程，不能卡住窗口或翻页。GPU 正在执行的算子不承诺瞬间中断。
- **音频时间是朗读时钟。** 句子结束再推进锚点，初版只承诺句子高亮；字级同步需额外对齐验证。阅读进度和朗读进度分别保存，恢复时由用户选择。
- **与漫画增强分开检测硬件。** NVIDIA CUDA 是第一阶段自定义声音的加速后端；AMD／Intel 能跑漫画 Vulkan，不代表可直接跑这套 CUDA 语音后端。失败或显存不足时保留正常阅读。
- **无 GPU 也有基础朗读路线。** 计划使用已安装的 Windows 系统中文声音作为轻量后备，它提供系统音色，不冒充用户选定的自定义音色。CPU 神经网络推理单独测速度；慢于实时则提示预生成或使用系统声音，不沿用“无显卡禁用漫画超分”来禁用全部朗读。[Microsoft 的系统语音接口](https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.speechsynthesizer?view=winrt-26100)。
- 小说文本默认只交给本机进程；联网仅用于用户主动下载组件与声音包。GPU 高负载时限制预生成，确保界面、动画和输入不等待语音生成。

## 声音包按需下载

把文件分为三层：语音运行引擎、共享基础模型、每个声音自己的参考／适配文件。**不同声线不等于每次下载一整套底模，也不等于一定要训练独立权重。** 零样本通过试听时，声音包可以只包含获得授权的参考材料和引擎支持的参考信息；微调文件仅在确有需要时加入，文件大小按实际产物显示。

源码仓库只放程序和声音目录说明。小型声音包可用独立 GitHub Releases 分发；大底模优先指向其官方 Hugging Face／ModelScope 文件并固定版本、大小和 SHA-256。GitHub Release [单文件需小于 2 GiB](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)，不能把大权重直接塞进普通 Git 提交，也不能靠本地缓存目录冒充已安装模型。

下载目录由用户选择，提供体积提示、进度、取消、删除、临时文件清理和断点恢复。维护者提供的声音目录需验证来源与签名，文件逐个校验摘要；模型加载限于受信来源和引擎支持的安全格式。下载记录同时绑定引擎／底模版本，检查不匹配时阻止加载。用户原始训练录音与访问凭据不进入源码包、普通安装包或诊断日志。

GPT-SoVITS 代码及其官方底模库标注 MIT；Qwen3-TTS 代码与所选 0.6B Base 模型标注 Apache-2.0。发布前按实际选中的全部文件核对许可，参考音频和第三方组件另列来源。[GPT-SoVITS 底模库](https://huggingface.co/lj1995/GPT-SoVITS)、[Qwen 模型卡](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)。训练生成的文件并非自动获得不限用途的发布授权。

## 阶段验收

| 阶段 | 交付与通过条件 |
| --- | --- |
| 0：清理与方案 | 无旧小说 AI 调用或密钥设置；配置恢复清除未知字段且保留阅读数据；不新增语音占位模块 |
| 1：独立试听 | 用第一批参考音频生成真实中文／日语样例；记录音色、读音、冷／热启动、RTF 与峰值显存，选定一个引擎版本 |
| 2：声音定型 | 必要时微调；同样的中文长文比较底模和新声音，不漏读整句、不反复重复、不在句间明显换声 |
| 3：阅读器接入 | 当前句起读、插画跳过、跨章、暂停恢复、手动翻页、全屏与换书取消均可用；播放不阻塞翻页 |
| 4：按需分发 | 只下载选定声音，共用底模不重复；失败下载不显示成功，取消和删除可回收文件，记录仍保留 |
| 5：兼容与发行 | NVIDIA 自定义声音、无 GPU 系统朗读分别验收；便携／安装与已有软件更新流程完成后再发布 0.9.7 |

实时朗读以本机热启动后 RTF < 1、预生成能跟上播放为目标，不把上游宣传延迟当作该电脑的实测值。每个阶段验证后再继续下一阶段。

**现在只需要第一批：一条目标声线、3 段干净短音频及准确日语原文、2–5 分钟备用语音、来源／可用范围说明，以及一小段希望试听的中文。先无需收集几小时音频或安装训练环境。**
