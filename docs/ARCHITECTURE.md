# 架构与资源边界

React 在 Tauri 2／WebView2 中显示界面。Rust 处理本地书架、来源读取、系统字体和 Waifu2x 子进程。ByteSource 提供随机读取，ReaderEngine 提供打开、定位、样式、翻页与销毁。

## 阅读与生命周期

- TXT／文字 EPUB 用 foliate-js 分页／连续排版，以 CFI 保存锚点；单双页为一栏／两栏，小说双页常驻书脊；上下模式按整屏对齐且绕过动画，滚轮／拖动和按键共用跨章边界。
- 漫画与 PDF 用源页索引定位；窗口与缩放决定固定页面框，单双页为一／两个等宽槽，图片和 PDF 页等比适配并留白。封面与末页的空白侧在静态布局中真实存在；快照捕获包含留白的页面框，卷页不按图片外接框重新居中、扩宽或补页。PDF 保留原排版与文字层，上下阅读仍用独立连续布局。
- 上下漫画最多挂载五页；拖动允许截页，翻页键直接对齐页顶。上下模式绕过卷页、滑动和翻书声。
- 卷页分别捕获左右纸张，以书脊为轴，上一页和下一页使用同一动画路径。
- 单页卷页的临时纸张同时复制 canvas 像素与开放 Shadow DOM 的样式／正文，避免副本只剩空壳；补丁由固定版本生成脚本维护。
- reading-input 把书内坐标转成正文坐标，统一左右半屏点击与 TurnGesture；turnPageSurface 负责旧页遮罩、准备目标页、鼠标进度、提交／回弹。只有源页索引和 CFI 导航分属两个阅读引擎。
- 小说 ResizeObserver 只在尺寸变化时重排，导航／动画期间延后执行；翻页前同步尚未处理的尺寸，字体和窗口变化均保留 CFI。动画使用原文档 CSS／DOM 的隔离快照，保留两端对齐、字距、字体与 SVG 插图；根尺寸使用实际几何避免多栏舍入累积，裁切与原分页容器一致，防止相邻栏漏入页边距。按章节和实际滚动位置识别插画页。捕获前完成字体／图片准备，整个翻页事务保留旧页遮罩，动态纸张在常驻书脊上方。超过约 2 MiB 的单章 DOM 使用即时切换，避免多份超大章节占用内存。
- 分页快捷键在捕获阶段统一处理，阻止内层分页器再次把同一次按键当作文字光标操作；文字选择的组合键保留原行为。
- 打开、关闭和导航分别串行；快速重复打开只提交最后一次请求。关闭时取消增强、等待翻页结束，再释放书籍、监听和快照。
- 原图尺寸决定 image-page-view 布局，增强只替换像素；对比线裁切增强图，原图与增强始终共用坐标。

## 增强

Anime4K 模型、GPU 回读和 PNG 编码在 Worker 内执行。使用高性能适配器；申请适配器实际支持的缓冲区上限。设备和滤镜管线复用，图片按带 32 像素重叠区的块处理，裁掉重叠区避免接缝。闲置一分钟或关闭书籍释放资源，切页在块边界取消过期工作。

每块从原图计算双轴高频和方向一致性掩码；密集网点保留原始纹理，线条区域使用模型输出。A 直接调用超分模型，移除重复的恢复模型，减少过度锐化与推理耗时。掩码与其他纹理复用并统一释放。

Waifu2x 使用 Rust 后台任务调用 ncnn Vulkan，支持符合驱动要求的 NVIDIA／AMD／Intel 硬件设备（包括核显），128 像素分块。排除 CPU 和软件适配器；没有硬件 GPU 时直接禁用，不运行 CPU 模型自检或失败重试。A 调用 cunet 超分，C 调用 cunet 降噪；B 在后台线程做保持尺寸的轻量边缘柔和处理，但整套增强入口仍须检测到硬件显卡。共用有界子进程等待与取消，失败保留原图并清理临时文件。

增强不阻塞导航。当前页先显示原图；结果只更新仍存在的页面。压缩结果采用 48 MiB LRU 缓存，当前页完成后顺序预处理后续两页。只缓存压缩图，预缓存不创建显示节点。A 为 2 倍，B／C 不改变尺寸。

## 数据

Rust 的 library.json 保存原路径与内容 SHA-256；移动后重新导入相同内容保留 ID 和阅读记录。写文件成功后才提交内存状态，损坏 JSON 备份后提示恢复。

WebView 存储保存设置、书签、分组和阅读时间（数据版本 4）；IndexedDB 保存封面和背景。一本书只属于一个分组，卷序由 bookIds 决定；解散分组保留书目，删书保留历史总阅读时间。计时采用单调时钟，离开正文、失焦、隐藏或打开管理面板时暂停。

便携 marker 在 Tauri 创建线程前同时指定 library 与 WebView2 数据位置，首次为空；个人／安装版使用原账户路径。安装包只写本应用 HKCU 键；卸载清理程序、快捷方式和安装键，用户未勾选删除数据时保留记录。

同名收录先统一标点、大小写、卷号，再匹配完整系列名；已有手工归属和 excludedIds 优先。新增卷按自然卷号顺序追加，保留手工卷序。封面只选当前可见成员，返回分组时随机轮换，读书计时更新不会重新选择。首页共用封面缓存与 lastRead。

图片背景压缩存储，视频直接以 Blob 保存到同一个 IndexedDB 键，只保留当前壁纸。视频静音循环，仅在书架显示且窗口有焦点时播放；阅读时卸载，失焦时暂停。Blob URL 在替换／卸载时释放。

## 上限

| 资源 | 边界 |
| --- | --- |
| 原生单次读取／前端区间 | 8 MiB／4 MiB |
| TXT／单图片或档案条目 | 128 MiB／64 MiB |
| ZIP | 30,000 条；拒绝越界、重复路径及超限解压 |
| 单次原生导入 | 200 个文件 |
| 压缩图缓存／上下挂载页 | 48 MiB／5 页 |
| 固定页动画快照／小说 DOM 快照 | 当前可见页面约 800 万像素／单章序列化约 2 MiB |
| 雨景 | 320 个雨丝、40 个水滴、300 万画布像素；隐藏时停帧 |
| 书架／分组编辑器 | 每页 60 张卡片／100 行 |
| 书架封面 URL | 当前 60 张卡片加最近阅读封面，最多 61 个 |
| 背景图片／视频 | 32 MiB／200 MiB；视频 H.264 MP4 或 WebM |
| Waifu2x 输入／输出 | 16 MiB PNG／8,000 万像素 |
| Anime4K 输出 | 8,000 万像素及适配器尺寸上限 |
| Waifu2x 队列／单步超时 | 运行和排队共 8 个／GPU 90 秒 |
| 音效 | 共用一个 AudioContext、两份解码缓存；雨声 30 秒片段，翻书最多两声音轨 |
| HTTP 区间缓存 | 8 MiB，严格区间、长度和版本检查 |

EPUB 去除脚本、外部资源加载和危险元素；书内 iframe 不允许脚本或桌面 IPC；书籍 ZIP 内容不落盘。HttpRangeSource 已实现和测试，尚未接入网盘账号。未使用的 chapterText／selectedText 与 textAvailable 已移除，后续朗读按真实场景重新设计。

漫画纸张使用一个 256×256 的复用纹理，以显示层正片叠底合成原图／增强图；卷页捕获使用同一纹理和混合方式。不同图片比例仍只影响固定槽内适配，主题不进入增强缓存键。仿真动画时长在两种阅读器共用的卷页事务中生效，限制为 150–1500 毫秒，上下阅读绕过。

更新由 app_updates 检查官方 HTTPS 清单、验证签名，再分别应用 NSIS 或便携包。便携包白名单只有程序与 runtime，拒绝越界路径、重复文件与链接，总解包上限 256 MiB；隐藏更新脚本退出后替换、失败回滚。无前端任意网络／执行接口。维护流程见 RELEASE.md，声音阶段见 VOICE_TRAINING.md。
